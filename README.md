# Лабораторна робота: Вступ до Django (за посібником Django Girls)

Цей проєкт створено відповідно до завдань лабораторної роботи на основі українськомовного посібника [Django Girls](https://tutorial.djangogirls.org/uk/).

## Структура проєкту

```text
djangogirls/
├── myvenv/              # Віртуальне середовище Python
├── mysite/              # Пакет налаштувань Django-проєкту
│   ├── __init__.py
│   ├── asgi.py
│   ├── settings.py      # Основні налаштування (TIME_ZONE, LANGUAGE_CODE, STATIC_ROOT тощо)
│   ├── urls.py          # Маршрутизація URL
│   └── wsgi.py
├── manage.py            # Утиліта керування Django-проєктом
├── db.sqlite3           # База даних SQLite (створюється після migrate)
├── python_intro.py      # Усі практичні приклади з розділу «Вступ до Python»
├── requirements.txt     # Залежності проєкту (Django)
└── README.md            # Конспект і опис лабораторної роботи
```

## Швидкий запуск (Windows PowerShell)

1. Перейти в папку проєкту та активувати віртуальне середовище:
   ```powershell
   cd C:\Users\denis\.gemini\antigravity\scratch\djangogirls
   .\myvenv\Scripts\Activate.ps1
   ```
2. Запустити приклади з розділу «Вступ до Python»:
   ```powershell
   python python_intro.py
   ```
3. Запустити локальний вебсервер Django:
   ```powershell
   python manage.py runserver
   ```
4. Відкрити у браузері адресу: `http://127.0.0.1:8000/`

## Короткий конспект розділів посібника Django Girls

### 1. Вступ
Посібник знайомить із повним циклом створення вебзастосунку (блогу) на Python та Django: від розуміння того, як працює Інтернет і командний рядок, до написання власних моделей, представлень (views), шаблонів і публікації сайту.

### 2. Встановлення
Для локальної розробки потрібно підготувати інструменти:
- **Python 3** — інтерпретатор мови програмування.
- **Командний рядок (термінал / PowerShell / cmd)** — інтерфейс для виконання команд (`cd`, `dir`/`ls`, `mkdir`, запуск Python і Django).
- **Редактор коду** та **Git** (для контролю версій).

### 3. Як працює Інтернет
- Вебсайт — це набір файлів (зокрема з кодом **HTML**), які браузер перетворює на вебсторінку.
- Файли сайтів зберігаються на спеціальних комп'ютерах — **серверах**, об'єднаних у глобальну мережу.
- Коли користувач вводить URL у браузері, формується **HTTP-запит (request)**, який через мережу (IP-адреси та DNS-сервери) доходить до потрібного сервера; сервер обробляє його і повертає **HTTP-відповідь (response)** (HTML, CSS, зображення тощо).

### 4. Редактор коду
Редактор коду (наприклад, VS Code, PyCharm, Sublime Text) надає підсвітку синтаксису, автодоповнення, керування відступами та інтеграцію з терміналом, що критично важливо для Python, де відступи визначають структуру коду.

### 5. Вступ до Python
Основні конструкції мови, відпрацьовані у файлі `python_intro.py`:
- **Типи даних:** числа (`int`, `float`), рядки (`str`), булеві значення (`True`/`False`).
- **Змінні:** іменовані посилання на значення.
- **Колекції:** списки (`list` — впорядковані, змінні: `sort`, `reverse`, `append`, `pop`) та словники (`dict` — пари «ключ: значення»).
- **Порівняння та умови:** `>`, `<`, `==`, `!=`, `and`, `or`, конструкція `if ... elif ... else`.
- **Функції:** визначення через `def назва(аргументи):`.
- **Цикли:** повторення дій за допомогою `for ... in ...` та `range()`.

### 6. Що таке Django?
**Django** — це безплатний вебфреймворк з відкритим вихідним кодом на Python. Він надає готові компоненти для типових задач веброзробки (робота з БД через ORM, маршрутизація URL, шаблони, форми, аутентифікація, адмін-панель).
Схема обробки запиту:
1. Вебсервер передає запит у Django.
2. `urlresolver` зіставляє URL із правилами в `urls.py`.
3. Знайдена функція-представлення (**view**) обробляє запит (за потреби звертається до бази даних) і формує HTML-відповідь, яка повертається користувачу.

### 7. Встановлення Django
- Створюється окрема папка проєкту (`djangogirls`).
- Створюється ізольоване віртуальне середовище (`python -m venv myvenv`), щоб залежності різних проєктів не конфліктували між собою.
- Середовище активується (`myvenv\Scripts\Activate.ps1` або `myvenv\Scripts\activate.bat`), після чого в командному рядку з'являється префікс `(myvenv)`.
- У файлі `requirements.txt` фіксується версія Django, і встановлюється командою `pip install -r requirements.txt`.

### 8. Ваш перший Django проект!
- Командою `django-admin startproject mysite .` генерується структура проєкту (`manage.py` і каталог `mysite/`).
- У `mysite/settings.py` налаштовуються `TIME_ZONE = 'Europe/Kyiv'`, `LANGUAGE_CODE = 'uk'`, `STATIC_URL`, `STATIC_ROOT = BASE_DIR / 'static'` та `ALLOWED_HOSTS`.
- Командою `python manage.py migrate` створюється база даних SQLite (`db.sqlite3`) та системні таблиці Django.
- Командою `python manage.py runserver` запускається локальний вебсервер на `http://127.0.0.1:8000/`.
