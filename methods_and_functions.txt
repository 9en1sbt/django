СПИСОК ВИКОРИСТАНИХ МЕТОДІВ, ФУНКЦІЙ ТА КОМАНД І ЇХ ПРИЗНАЧЕННЯ
(Практикум: Вступ до Python та перший проєкт на Django)

====================================================================
1. ВБУДОВАНІ ФУНКЦІЇ PYTHON (python_intro.py)
====================================================================
- print(...) — виводить текст, значення змінних або результати виразів у консоль.
- len(obj) — повертає довжину (кількість символів у рядку, кількість елементів у списку або кількість пар ключ-значення у словнику).
- str(obj) — перетворює переданий об'єкт (наприклад, число) у рядок (тип str).
- range(start, stop) — генерує послідовність цілих чисел від start включно до stop не включно (використовується у циклах for).

====================================================================
2. МЕТОДИ РЯДКІВ (str)
====================================================================
- .upper() — повертає копію рядка, переведену у верхній регістр (великі літери).

====================================================================
3. МЕТОДИ СПИСКІВ (list)
====================================================================
- .sort() — сортує елементи списку на місці за зростанням.
- .reverse() — змінює порядок елементів списку на протилежний.
- .append(item) — додає новий елемент у кінець списку.
- .pop(index) — видаляє елемент за вказаним індексом (за замовчуванням останній) і повертає його значення.

====================================================================
4. МЕТОДИ СЛОВНИКІВ (dict)
====================================================================
- .pop(key) — видаляє пару «ключ: значення» зі словника за вказаним ключем і повертає видалене значення.

====================================================================
5. ВЛАСНІ ФУНКЦІЇ (python_intro.py)
====================================================================
- main() — головна функція скрипту, яка послідовно запускає всі приклади з розділу «Вступ до Python».
- hi_greeting(person) — виводить персоналізоване привітання залежно від переданого імені (if / elif / else).
- hi(girl_name) — виводить привітання для кожного імені зі списку у циклі for.

====================================================================
6. ФУНКЦІЇ ТА МЕТОДИ У ФАЙЛАХ DJANGO-ПРОЄКТУ (mysite/, manage.py)
====================================================================
- Path(__file__).resolve().parent.parent (mysite/settings.py) — визначає абсолютний шлях до кореневої директорії проєкту (BASE_DIR).
- os.environ.setdefault(...) (manage.py, wsgi.py, asgi.py) — встановлює змінну середовища DJANGO_SETTINGS_MODULE для підключення файлу налаштувань mysite.settings.
- execute_from_command_line(sys.argv) (manage.py) — обробляє та виконує адміністративні команди Django, передані з командного рядка.
- path(route, view) (mysite/urls.py) — зіставляє URL-адресу з відповідним обробником (наприклад, admin.site.urls для адмін-панелі).
- get_wsgi_application() (mysite/wsgi.py) — створює WSGI-застосунок для розгортання проєкту на вебсерверах.
- get_asgi_application() (mysite/asgi.py) — створює ASGI-застосунок для асинхронної роботи вебсервера.

====================================================================
7. ОСНОВНІ КОМАНДИ ТЕРМІНАЛУ, VENV, PIP ТА DJANGO
====================================================================
- python -m venv myvenv — створює ізольоване віртуальне середовище Python у папці myvenv.
- .\myvenv\Scripts\Activate.ps1 — активує віртуальне середовище у PowerShell (Windows).
- pip install -r requirements.txt — встановлює всі залежності (бібліотеки), перелічені у файлі requirements.txt.
- django-admin startproject mysite . — створює початкову структуру Django-проєкту у поточній папці.
- python manage.py check — перевіряє проєкт Django на наявність помилок конфігурації.
- python manage.py migrate — застосовує міграції та створює таблиці у базі даних (db.sqlite3).
- python manage.py runserver — запускає локальний вебсервер розробки (за замовчуванням на http://127.0.0.1:8000/).
